# angular-auth-example

Zoneless Angular app (Signal Forms) that logs in against `dotnet-fe-auth`, stores the JWT and calls protected endpoints.

## Run

1. Run `npm run setup` once (repo root): it exports the dev certificate and sets the API signing key.
2. Start the backend: `npx nx run dotnet-fe-auth:run`.
3. `npx nx serve angular-auth-example`. Requests to `/api` are proxied to `https://localhost:5001`.

## API client

`src/api-integration/api.ts` is generated by Orval (Angular `HttpClient` service) from `apps/dotnet-fe-auth/wwwroot/api/v1.json`. To export the spec and regenerate the client:

```sh
npx nx run angular-auth-example:generate-client
```

## Token storage caveat

The JWT is kept in `localStorage` and attached by `auth.interceptor.ts` to `/api` requests only. This keeps the demo simple, but any script running on the page can read it. Real apps should use HttpOnly cookies or a backend-for-frontend (BFF) instead.
